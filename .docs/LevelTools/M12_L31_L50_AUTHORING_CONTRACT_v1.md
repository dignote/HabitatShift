# M12 L31–L50 authoring contract, version 1

M12 balances **50% of the gameplay and composition DNA of L19–L30** with **50% new-system evolution**. Density supports the puzzle; it never overrides solvability.

The L19–L30 half calls for high physical occupancy, usually 8–12 physical Habitats, many colors, duplicate colors, footprint competition, meaningful Elevator queues, compact maneuvering, and purposeful interleaving.

The evolution half calls for Dual-Ring stage dependencies, spatial lock/key relationships, moving one Habitat to open another route, central interlock clusters, topology with gates and pockets, and staged queue dependencies. Dual-Ring is not a reason to make boards sparse.

| Levels | Target density |
| --- | --- |
| L31–35 | 76–85% |
| L36–40 | 80–88% |
| L41–45 | 82–90% |
| L46–50 | 84–91% |

Density is `(Habitat footprint cells + initial Sproutlings + blockers) / playable cells`, matching the existing composition audit. See `m12_l31_l50_authoring_contract_v1.json` for machine-readable gates. Use the M11 production audit as the frozen comparison baseline. Candidate levels need stage/supply/placement/mobility/reachability/queue dependency audits, alternate-order checks, and winning solution traces. Static checks alone cannot certify a level.
